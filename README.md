# Optimization Techniques Assignment

Python implementations of optimization techniques for the Optimization
Techniques course.

## Methods Implemented

### 1. Big-M Method
Python implementation of the Big-M method for solving Linear Programming
problems.

### 2. Vogel's Approximation Method (VAM)
Used to obtain an Initial Basic Feasible Solution for a Transportation Problem.

### 3. MODI Method
Used to test the transportation solution for optimality and improve the
allocation iteratively.
